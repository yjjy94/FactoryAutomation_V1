## 프로젝트 소개

본 프로젝트는 컨베이어 기반 제조·물류 환경에서 **제품 실시간 불량(손상) 감지, QR코드 기반 주문 및 고객 관리, 하드웨어 자동 제어**를 통합한 시스템입니다.

- 실시간 영상처리 및 손상/불량 탐지  
- 제품 QR코드 인식/생성 및 DB연동  
- 아두이노 기반 컨베이어·모터 제어  
- MFC UI를 통한 신규 주문·고객 등록 및 QR 이미지 저장  

---

## 주요 기능

- **실시간 손상/불량 감지:**  
  OpenCV 및 YOLO 모델 기반 카메라 영상에서 제품 손상 탐지
- **QR코드 인식 및 검증:**  
  제품 QR코드를 읽어 DB 내 주문과 연동
- **아두이노 하드웨어 제어:**  
  불량 감지 시 컨베이어·모터·서보 자동 제어
- **고객 및 주문 데이터 관리:**  
  신규 주문/고객 등록 시 QR코드 생성 및 저장
- **모듈화 구조:**  
  영상, 데이터베이스, 하드웨어, UI 로직이 분리되어 유지보수 용이

## 시스템 아키텍처
[MFC UI]
↓
[C++ 로직]
├─ OpenCV/YOLO: 영상·손상탐지
├─ QR코드 인식/생성
├─ MySQL 연동: 주문·고객 DB
└─ 시리얼통신: Arduino(하드웨어)
↓
[Arduino]
↓
[컨베이어, 서보, 센서 등 제어]

---

## 프로그램 동작 개요

1. **MFC UI**에서 고객/제품 정보 입력, 주문 생성  
2. 신규 고객/주문일 경우 DB에 자동 등록  
3. 주문번호 기반으로 QR코드 생성, 이미지 파일(JPG)로 저장  
4. 영상 입력(카메라)에서 실시간 제품 인식, 손상(불량) 탐지  
5. 불량 감지 시 자동으로 컨베이어/서보 모터 제어  
6. QR코드 판독 시, 주문/고객 데이터와 매칭해 정보 확인  
7. 전체 과정은 DB와 연동되어 이력 관리 및 추적 가능
